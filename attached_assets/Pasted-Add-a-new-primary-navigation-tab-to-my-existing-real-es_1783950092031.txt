Add a new primary navigation tab to my existing real estate equity-tracking website called:

**Finances**

Within the Finances tab, create a real-estate-specific bookkeeping and CPA preparation system for long-term rentals and short-term rentals.

The purpose is not to recreate the full complexity of QuickBooks. The purpose is to let real estate investors track income, expenses, loans, improvements, owner activity, and supporting documents by property, then generate clean property-by-property reports that can be given to a CPA.

## Important development requirements

Before writing code:

1. Review the existing application structure, database schema, authentication system, property records, user accounts, components, styling, and navigation.
2. Reuse the existing technology stack, database, design system, authentication, and property IDs.
3. Do not rebuild or replace existing working features.
4. Do not remove or rename existing database fields without confirming they are unused.
5. Make all database migrations backward-compatible.
6. Make the new Finances area consistent with the existing website's visual design.
7. Ensure each user's financial information is private and isolated from every other user.
8. Ensure users can only access properties and transactions belonging to their own account.
9. Build responsive layouts for desktop, tablet, and mobile.
10. Use realistic empty states instead of inserting fake financial data into production accounts.

# 6. Repairs versus capital improvements

Whenever a user enters or categorizes a large property-related expense, provide a clear classification selector:

* Repair
* Maintenance
* Capital improvement
* Depreciable asset
* Unsure — ask CPA

Show brief educational guidance:

* Repair: generally restores something to its previous working condition.
* Maintenance: routine work intended to keep the property operating.
* Capital improvement: generally adds value, extends useful life, or adapts the property to a new use.
* Depreciable asset: a separately identifiable item such as furniture, equipment, or an appliance.

Do not present this guidance as definitive tax advice.

If the user selects “Unsure — ask CPA,” include the transaction in a CPA questions report.

Flag potentially significant expenses for review based on a configurable dollar threshold. Do not automatically make the final tax classification for the user.
